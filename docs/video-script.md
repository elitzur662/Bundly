# Bundly — תסריט וידאו הדרכתי ללקוח חדש

**משך כולל מומלץ:** 4-5 דקות
**סגנון:** מסך מלא של האתר + voice-over בעברית, בלי דובר על המסך
**רזולוציה:** 1920×1080, צילום מסך + cursor highlights

## 📝 הערות לכלי הוידאו

### דרישות טכניות:
- **רזולוציה:** 1920×1080 (16:9) או 1080×1920 (9:16 לטיקטוק)
- **FPS:** 30
- **Cursor:** ניראה, גודל קצת מוגבל מהרגיל (1.3x), לחיצות עם click-effect (עיגול אדום קצר)
- **Highlights:** 5px outline אדום-זוהר על אלמנטים מודגשים
- **מעברים:** Cut מהיר בין סצנות (לא fade), 0.2s

### קריינות:
- **שפה:** עברית
- **טון:** ידידותי, מקצועי, לא דחוס
- **קצב:** 130-150 מילים לדקה (לא מהיר מדי)
- **רעש רקע:** מוסיקה אוקיי-עם-קולות בעוצמה -20dB

### Voice-over alternatives:
1. **AI:** ElevenLabs (קולות עברית טבעיים — "Daniel" / "Adam") או Google TTS
2. **Human:** דובר עברית עם מבטא ניטרלי
3. **טקסט-בלבד:** subtitle בעברית במקום voice-over

### Screen recording tips:
- מומלץ להקליט במצב incognito (בלי extensions פרסומת)
- צילום מסך טהור — בלי הודעות OS
- Browser zoom 110% לקריאות
- אינדיקטורים של זמן/סוללה מוסתרים

## 📊 קטעים אופציונליים (אם זמן זמין)

### בונוס 1 — דשבורד ספק (30s)
איך הספק מציע מחיר: דשבורד → קבוצות פעילות → לחיצה על קבוצה → הקלדת הצעת מחיר → שליחה → הצעה מופיעה ללקוח.

### בונוס 2 — pre-auth payment (45s)
הסבר מפורט על מנגנון הקפאת הכרטיס: "הסכום מוקפא בלבד, לא חויב. אם הקבוצה לא נסגרת — הסכום משוחרר אוטומטית. אם נסגרת — הכרטיס מחויב במחיר הסופי, מקוזז את המקדמה."

### בונוס 3 — הזמנת חבילה (Bundle, 30s)
חבילת "מעבר דירה" — כל המוצרים החיוניים במחיר אחד (מקרר + מכונת כביסה + תנור + מזגן + מדיח). חיסכון של 18-25% מקנייה נפרדת.
